# Revised non-application figures and statistics

Run `python update_assets.py` with NumPy, SciPy, and Matplotlib available.
Tested analysis runtime: Python 3.9 and Matplotlib 3.3.3. Plot helpers are
vendored in `retained_plot_helpers.py`; no LAMMPS Python interface is required.

The command regenerates the affected main Figures 2--6 and SI Figures S3--S8,
four statistical table inputs, and their analysis CSVs. It writes vector PDFs
to `../01_manuscript_tex_and_source/` and high-resolution PNGs here.
Figure 1, exact/closure Figures S1--S2, and application Figures 7--8/S9--S15
are retained assets and are not regenerated by this command.

## Data selection

- `data/recomputed/timeseries`: new rank-local-RNG fast trajectories and the
  corresponding retained reference snapshots.
- `data/retained/core`: single-rank validation and timing data.
- `data/retained/incremental`: single-rank mobile controls.
- `data/timing_records.csv`: explicit timing cohorts and library provenance.
  `legacy` means the fixed-size/serial benchmark geometry; `size3d` means
  the new three-dimensional size sequence. The same atom count in the two
  cohorts is **not** the same benchmark and must not be pooled.
- `data/provenance`: task completion, runtime, source and library hashes,
  CPU topology, affinity probes, and regression summaries.

No affected old parallel fast trajectory is appended to a new chain.
Continuation segments count as one replica, not independent seeds.
Mobile statistics use actual MC-instant snapshots; segment-end MD-only
records are excluded. Mean differences use three seed replicas and
correlation/block-aware uncertainty, as defined in the SI.
Timing ratios use independently measured mean times with log-scale
delta-method intervals, not artificial pairing of historical and new runs.
No best-run filtering or curve smoothing is used.

For the retained reference ternary/ZBL acceptance fractions, use the audited
counter increments in `data/retained/audit/acceptance_rechecked.csv`, not
differences of reset counters across concatenated continuation segments.

These scripts do not analyze or modify the phase-diagram application.

## Concise manuscript edition

Only Figure 4 is restyled in this edition. Regenerate it with
`python update_assets.py --figure4-only`. Dark, offset N/N^2 guides are
directly labelled; their arbitrary normalization is recorded in
`figure4_guide_audit.json`. Input times, uncertainties and fitted exponents
are unchanged. The ordinary full command remains available for reproducing
the entire validation figure set.
